## 3. Questions research must answer

### Engine / runtime

1. Can we ship a **wet night strip** on **mid-range Android Chrome** without flags?
2. Three.js + postprocessing vs Babylon vs raw WebGPU / custom: fit for PBR wet floor + rain + ribbon?
3. What is the **minimum** for portfolio still quality (planar reflection? SSR-lite? cube env only)?
4. If WebGPU is required for Snowflow-class look, is desktop-first portfolio OK for v0?

### Art / fidelity path

5. Wet asphalt recipe that survives mobile (normal + roughness + fake reflection plane)?
6. Rain: particles vs screen-space streaks vs hybrid; budget per frame?
7. Neon: emissive materials + bloom budget; avoid full bloom mush on phone?
8. Wind ribbon: mesh tube vs ribbon particles vs shader trail - which reads as "expensive"?

### Feel / sim

9. Draw on touch: project stroke onto bend plane vs free 3D curve - mobile accuracy?
10. Ride: spline follow with snappy accel - headless test plan (Inkfall physics-test pattern)?
11. Breath multi-try: simple meter; cancel incomplete stroke cost?

### Product / scope

12. One-strip content budget: length, one landing lantern, zero vs two adversary verbs?
13. Deploy: Vite + static vs raw; domain timing relative to still quality?
14. Audio: wind bed + commit SFX - defer or include in spike?
